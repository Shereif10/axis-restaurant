# AXIS Restaurant & Cafe — Premium Website

A high-impact, animated one-page restaurant site built with semantic HTML, CSS and GSAP/ScrollTrigger.

## Run
Open `index.html` directly, or use any static server.

Example:
- VS Code Live Server
- `npx serve .`

## Notes
- All photography and menu artwork in this build comes from the assets supplied for the AXIS project.
- No placeholder images are used.
- GSAP and Google Fonts load from CDN when internet is available.
- Menu sheets open in a full-screen viewer and can be navigated with arrows or keyboard.
